# Easy串口助手 v2.0

PyQt6 + pyserial,深色主题串口调试工具。

## 运行
```
pip install -r requirements.txt
python main.py
```

## 打包为单文件 exe
```
build.bat        # 输出 dist\EasySerial.exe
```

## 本版新增 / 优化
- 发送功能区:ASCII/HEX 格式、ASCII 行尾符、定时发送、6 个右键可编辑的快捷指令；HEX 始终发送原始字节
- 串口真正打开后才允许发送，写入失败/部分写入有明确提示，发送成功后带 TX 标记回显
- 工具箱新增「自动回复」:多规则、ASCII/HEX、完全/包含/正则匹配、自定义回复和防循环间隔
- 状态栏 TX 字节计数
- 工具箱新增「时间戳转换」(Unix 秒/毫秒 ↔ 日期,双向)
- HEX 双栏:每行字节数随栏宽自适应(自动换行);右栏每字节固定 1 字符(不可见字节显示 ·),与左栏逐行严格对齐
- 纯 HEX:按宽度强制分行 + 批量刷新,大数据量不再卡顿
- 全部日志区改用 QPlainTextEdit + 原生行数裁剪(默认 5000 行),内存恒定
- Ctrl+滚轮 / A± 改字号:字体只挂在控件级,全文瞬间生效,无重格式化卡顿
