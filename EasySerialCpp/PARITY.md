# C++ / Python 功能核查

本轮以仓库内 `ui/`、`core/` 的 Python 实现为行为基准。Python 代码和原根目录 `dist` 未修改。

## 已修复并自动验证

- 名称与语言：发布文件为 `dist/EasySerial.exe`；窗口标题、按钮、工具、提示和错误文本为英文。旧默认快捷指令名按名称、内容和格式三项匹配迁移，用户自定义内容不变；内部配置 ID 保留以兼容旧配置。
- 图标：原创信号芯片 SVG，构建时生成 16/24/32/48/64/128/256 像素 Windows ICO；EXE 资源与窗口图标同步。发布包启动检查同时验证图标插件加载。
- 字号：新配置默认 9 pt；A± 统一设置并保存全部数据窗格字号，Ctrl+滚轮按接收模式/发送窗格分别调整并立即保存。重新加载配置后恢复各自字号及右上角显示；更改配色不再重置字号。行距由原生文本布局随字体计算，没有固定表格行高。
- 外观：ASCII、HEX、双栏 ASCII、时间戳和背景颜色即时更新；既有数据随规则修改重绘。发送区同时应用字体和颜色。
- 时间戳：改为“[时间戳] RX/TX”独立分组头，下一行正文；ASCII 同方向后续数据连续追加，达到时间间隔后仍需等到接收块之间的真实 CR/LF 行边界才添加下一个头，不截断未结束的一行。收发方向变化时新建带时间戳的分组，避免误标。关闭时间戳后只保留分组方向。HEX 按帧显示。
- 搜索：实时搜索、匹配计数、全词、大小写、正则、双向循环、命中高亮、Esc 关闭、Shift+Enter 上一项。最多计数 5000 个命中。
- 显示：三种模式使用只读 QTextEdit，保留原生字符选择并支持像素级滚动；ASCII/纯 HEX 原生软折行，HEX 双栏随宽度重排并同步滚动。支持字符级鼠标拖选、跨视觉折行选择、原始帧 HEX 复制；新数据追加和字号/窗口改变保留现有字符选区。文本格式只指定颜色，既有文字随默认字体一起缩放。
- 平滑滚动：自动跟随和鼠标滚轮上下滚动均固定使用约 16 ms 动画节拍，不再提供 Smooth scroll 开关，也不读取旧配置中的动画关闭选项。连续输入只更新目标，不排队播放；自动跟随超过两屏的突发直接追到最新。支持滚轮快速反向、像素增量、系统滚动行数、HEX 双栏同步，Ctrl+滚轮仍调字号。
- 自动跟随：只由 Auto scroll 勾选状态决定；开启时新数据始终追到最新，滚轮、选字、搜索不自动关闭跟随，没有 Back to latest 按钮。关闭后才能保持历史阅读位置。常规帧裁剪增量移除前缀并维持阅读锚点；超大边界帧仍裁剪保留其尾部，必要时重建有界文档。
- 显示分帧：底层按串口空闲间隔（默认 20 ms）及 4096 字节上限分块保存原始数据，但这些边界不再产生 ASCII 换行。ASCII 保留真实换行及尾部空行，跨块 CRLF 只换一次；正常界面与监控浮窗共用实现。HEX 仍显示独立数据块，自动回复分帧保持独立。串口没有通用协议报文边界，不能把上述数据块当作协议消息。
- 发送：UTF-8、ASCII 行尾选项、HEX 严格原始字节、不合法 HEX 拒绝、空快捷指令不误发 CR/LF。
- 自动回复：ASCII/HEX 规则匹配、HEX 回复不追加行尾；保留原有冷却及回显防环路处理。
- 工具：ASCII/HEX 转义双向转换（修复 `\\xNN` 被错误变成 `\\XNN`）、CRC16、SHA256。
- 配置：旧默认深色迁移为浅色；自定义颜色保留；保存和重新读取验证；主分隔条状态持久化。
- 监控浮窗：同一接收视图在正常界面与无边框置顶浮窗之间切换，保持文档、字符选区、帧历史、发送草稿和定时器；不重建串口连接。背景单独透明，像素测试验证正文保持不透明。监控字号独立保存，滑栏与 Ctrl+滚轮同步。支持标题拖拽、四角吸附、自由定位、边缘缩放、恢复主窗口和多次往返；恢复原窗口几何位置、最大化、置顶及分隔条布局。覆盖负坐标屏幕的定位计算、缺失显示器恢复和浮窗打开时主对象销毁。
- 浮窗快捷控制：原标题栏内增加串口开关、自动滚动和清屏图标，位置菜单改成图标，窗口默认/最小尺寸与正文高度保持紧凑。连接状态来自实际串口信号，操作期间禁止重复点击；无端口提示、无效端口失败/重试在浮窗内可见。自动滚动与主界面双向同步、持久化；清屏共用正常界面逻辑。回归覆盖最小窗口无重叠、真实视图跟随/暂停、重复往返无重复信号及清屏时未提交数据丢弃/草稿与计时器保留。串口测试只使用不存在的设备路径，未操作真实设备。

## 设计和实现差异

- 默认白色数据区、浅灰蓝底、蓝色主按钮；中文使用微软雅黑回退。
- 接收区已改为与 Python 版同类的原生文本控件；按帧保存原始字节，批量追加文本，保留缓存上限。搜索作用于当前左侧文本视图，包括时间戳与方向标题，最多 5000 个命中。
- C++ 的日志为无损转义格式（非法 UTF-8 保留 HEX），而非 Python 的有损文本解码日志。
- 不照搬 Python 的界面冻结风险：文件 SHA256 使用后台线程；串口发送按驱动确认统计。
- C++ 的 PB Decoder 已扩展为运行时导入多个 `.proto`，使用官方 Protobuf 导入器/动态消息，TaskBatch 仅作为示例。支持独立协议切换、带包名/嵌套消息、跨目录 import、标准协议、中文路径、Reload、Remove，以及协议列表和消息选择持久化。测试继续覆盖用户原始样本 byte 24 起的批次号、任务号、周期列表及 bytes，并新增全标量、packed/unpacked、map、oneof、proto2 默认值/required/扩展、依赖缺失/语法错误、同名版本隔离、超限和旧结果清除。输出为调试 JSON（bytes HEX、64 位整数字符串、枚举数字），不是标准 ProtoJSON；bytes 内的其他业务协议不会递归猜测。

## 验证边界

`build.ps1` 运行 Qt 原生渲染回归测试，再部署依赖到构建中间目录，打包并验证单文件启动，全部成功后才发布到独立 `dist/EasySerial.exe`。单文件测试将 EXE 独立复制到无 DLL 的路径，清除 Qt 开发环境路径，验证并发运行、监控模式往返和退出清理。测试使用临时配置，不修改真实串口设置，不向设备发数据。截图在 `build/artifacts`。

未自动验证真实串口设备的长时间高吞吐收发、拔插恢复、自动回复实际设备时序和全部 Windows DPI/字体组合；本轮不能宣称所有设备场景已验证，也不能把编译成功当成功能完全一致。
